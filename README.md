# Serviços de Turismo e Viagens - GUI

Página estática desenvolvida para a Atividade Prática Final de Introdução ao HTML5.

## Recursos utilizados

- Estrutura semântica com `header`, `nav`, `section`, `figure`, `figcaption` e `footer`
- Mídia nativa com `video` e `audio`
- Formulário com tipos modernos de entrada
- Gráfico em `canvas`
- Mapa incorporado com `iframe`
- Layout responsivo com CSS

Este repositório está pronto para ser publicado no GitHub Pages usando a branch `main` e a pasta raiz.
